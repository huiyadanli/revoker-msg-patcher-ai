## 目录规范

- 主记录：`QQNT_<应用版本>_wrapper.node_<PE文件版本>_防撤回研究.md`，每个版本一份，历史条件反转方案保留在相应记录内。
- [证据归档](evidence/)：按相同的双版本组合分目录，区分安装前分析、运行时复核、安装后字节以及用户反馈。
- [工具说明](tools/README.md)：只读分析器、当前特征验证源码和 REA / IDA 配置经验。

清理了编译产物、重复反汇编、重复摘要、空证据包、临时源码副本和过期实验脚本。REA 应用包大证据以 `.json.gz` 无损保留。助手没有自行执行撤回事件，用户未提供的具体场景不补记为测试通过。
